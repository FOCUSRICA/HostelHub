# HostelHub starter prototype

This is a separate static website prototype for a student accommodation platform.

## Open it
- Open `index.html` in a browser, or publish this folder as a separate GitHub repository.
- Keep the complete folder structure: `index.html`, `css/style.css`, and `js/app.js`.

## Included
- Responsive landing page
- Sample hostel listing cards
- Search by sample location/hostel and room type
- Demo listing detail dialog
- Mobile navigation

## Important
- The hostel listings and prices are fictional placeholders for design demonstration.
- Sign-in, applications, database storage, payment processing, payment verification, and account restrictions are NOT connected yet.
- Do not collect real student information or accept real payments in this prototype.
- The next development stage is to create a separate Firebase project, configure Authentication and Firestore, and define security rules before connecting real data.
